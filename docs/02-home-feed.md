# 首页、信息流、动态与评论

首页与内容流接口。分页通常使用 `page`/`firstItem`/`lastItem`；`lastItem` 取自上一页最后一个卡片，`firstItem` 用于下拉刷新。注意：coolapk-desktop 的探针显示部分写接口（点赞、回复、关注、发私信）GET 可用而 POST 返回“请求方式错误”，但旧文档与生产代码仍写 POST；表格同时保留两种方法。2026 年的 macOS 客户端已将 `feed/hotReplyList` 替换为 `feed/replyList?listType=popular`，但 2026-10-15 实测 `feed/hotReplyList` 仍能返回数据。
