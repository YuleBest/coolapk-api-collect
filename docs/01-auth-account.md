# 账号与鉴权

登录态相关接口。公开读取接口通常只需要 `X-App-Token`；以下接口若标注 Cookie，则需要携带 `token`/`username`/`uid`。Token 与设备码的 v1/v2/v3 三代生成方式见 `00-overview.md`。`account.coolapk.com` 的登录/注册接口以 HTML 表单与 Cookie 为主，`api.coolapk.com/v6/account/*` 才是 JSON 接口。

共 20 个端点。标记含义：`verified` 至少两个独立项目源码出现；`single-source` 仅一个项目源码出现；`doc-only` 仅文档来源。
参数列保留原始提取文本，Retrofit 注解（如 `@Query("id")`）与类型信息未做二次改写；完整未截断内容见 `endpoints.json`。
