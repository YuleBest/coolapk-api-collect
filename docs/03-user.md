# 用户与收藏

用户资料、主页内容、关注关系、收藏单与历史记录接口。用户参数多用 `uid` 或 `username`；写操作需要登录 Cookie。coolapk-desktop 的探针中 `user/pictureList`、`user/ershouList`、`user/favList` 返回 404，文档也标注其已下线，但生产代码仍保留兼容调用。
