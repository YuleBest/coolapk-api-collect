# 通知与私信

通知、私信与系统消息接口。全部需要登录态；未登录时 `account/checkLoginInfo` 的 `notifyCount` 可作为消息数量来源。`message/send` 存在 GET/POST 方法冲突，与动态写接口相同。

共 24 个端点。标记含义：`verified` 至少两个独立项目源码出现；`single-source` 仅一个项目源码出现；`doc-only` 仅文档来源。
参数列保留原始提取文本，Retrofit 注解（如 `@Query("id")`）与类型信息未做二次改写；完整未截断内容见 `endpoints.json`。
